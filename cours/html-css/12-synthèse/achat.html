Acheter un jeu vidéo

L'achat d'un jeu vidéo est non remboursable. À choisir avec prudence.

  1. Savoir si ce type de jeu vous convient.
  2. Savoir si votre PC peut supporter le jeu.
  3. Assurer vous que le jeu n'est pas une arnaque
